# Refund & Returns Policy

## 1. Standard Return Window

Pearlz Home Systems accepts returns of AquaPearl units within **30 days of
the delivery date**, for any reason.

## 2. Returning an Opened or Used Unit

The 30-day return window **still applies even if the unit has been opened,
installed, or used.** However, a **15% restocking fee** is deducted from the
refund for any unit that has been opened or used, to cover reconditioning
costs. Unopened units in original packaging are refunded in full.

## 3. How to Initiate a Return

1. Contact Pearlz Customer Support to request a Return Merchandise
   Authorization (RMA) number within the 30-day window.
2. Pack the unit securely, including all original accessories.
3. Ship the unit back using the prepaid return label provided with your RMA.
4. Refunds are issued to the original payment method within 10 business
   days of Pearlz receiving the returned unit.

## 4. Non-Returnable Items

- Replacement filter cartridges that have been installed/used are not
  eligible for return for hygiene reasons.
- Units returned after the 30-day window are not eligible for a standard
  refund; customers should instead refer to the Warranty Policy for
  defect-related claims.

## 5. Discounts and Promotions

Pearlz does not offer student discounts. Any discount codes must appear on
an official Pearlz promotional communication; Customer Support cannot apply
unlisted or speculative discounts to an order.
